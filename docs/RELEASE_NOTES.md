# 忙僧 busy·blind — 首次 Android 公开版（草稿）

给忙碌的生活，留一点安静。

忙僧是一款以声音互动为主的专注与呼吸练习 App。这次发布面向 Android，项目代码采用 MIT 许可证。

## 体验内容

- 木鱼、数雨、听潮、钓花和过河五种练习。
- 打坐、每日一签、修为与成就、花瓣收集和花朵图鉴。
- 本地修行记录，以及可选的 AI 修炼报告。

## 安装

下载本 Release 附件中的 `.apk`，在 Android 手机上打开安装。源码压缩包不是安装包。首次使用请跟随教程，建议佩戴耳机。

## 当前范围

- 暂不提供 iOS 版本；好友联网功能尚未开放。
- 核心练习无需 API Key。AI 报告需自行配置服务，可能产生第三方费用；也可以使用本地模板。
- 数据保存在本机，暂无云同步。清除应用数据或卸载可能丢失记录。
