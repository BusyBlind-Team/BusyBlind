## 核对原则

- 爱给网不是统一许可证：付费素材看实际授权书，CC 素材看具体条款，未标注许可不能当作允许公开分发。
- CC0 素材通常允许复制、修改和分发；仍保存来源证据。
- CC BY 素材保留其许可证，补齐作者、作品链接、许可链接和修改说明；不要把音频重新标成 MIT。
- 带 NC、ND、SA 的素材分别核对用途、修改和共享条件；首次发布优先选择团队原创、CC0 或授权清晰的 CC BY 素材。
- 商用授权不等于允许原始文件再分发。APK 内使用与把音频直接放进 GitHub 分别核实。
- 后续如发现素材存在授权问题，按具体情况取得授权、替换或移除，并检查安装包与 Git 历史中的旧版本。
