## 音频压缩

| 指标 | 压缩前 | 压缩后 | 变化 |
| --- | ---: | ---: | ---: |
| 文件数 | 16 WAV | 16 MP3 | key 数不变 |
| 总体积 | 2,376,370 B | 446,774 B | -1,929,596 B（-81.2%） |

- 短音效采用 128 kbit/s；森林、潮汐循环采用 64 kbit/s；声道数与采样率分层保持原设计。
- `tool/gen_sounds.dart` 先在 `build/generated_audio_pcm/` 生成临时 PCM WAV，再调用 FFmpeg 无元数据转码；成功后删除中间文件，找不到 FFmpeg 时输出明确错误。
- 使用 `FFMPEG_PATH` 从头执行脚本后，16 个 MP3 与交付资产逐字节一致。
- FFmpeg 完整解码检查 16/16 通过；release APK 中包含 16 个 MP3、0 个 WAV。
